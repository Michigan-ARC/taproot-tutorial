# Taproot Tutorial

Welcome to the Taproot Tutorial! This guide will teach you how to program a RoboMaster robot using the Taproot control library.

Taproot provides a Command-based architecture, hardware abstractions for DJI motors, and highly optimized control algorithms.

### How this site works
This site is built using [Docsify](https://docsify.js.org/). It requires no build step. To host this on GitHub Pages:
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages**.
3. Select the branch you pushed to, choose the `/ (root)` folder, and click **Save**.
4. In a few minutes, your Taproot tutorial website will be live!
